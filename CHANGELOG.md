# Changelog

The latest release has its entry here. It lists what changed since the
previous tag. A project that clones Tadas at a release checks out its
tag, such as `git clone --branch v0.7.0`.

## 0.15.0 (2026-09-30)

A clone of Tadas at this tag finds a gateway whose log filter drops a
request's target in any form, and the pin at guideline v0.46.0, where
the count of a manager interface's operations says where a review
looks and fails no build. No route, wire type, screen, or migration
changes, and nothing is reversed.

- **The gateway's log filter drops a request's target in any form.** It
  finds the target by its place in uvicorn's line and writes a dash
  there. In 0.14.0 a target in absolute form, or with no leading
  slash, reached uvicorn's lines with its path and its query string. A
  test opens a socket through uvicorn's own protocol with a target in
  each form. (#196)
- **A manager's count asks for a review.** At the pin, `arch-check`
  names a manager interface past twenty operations on a `to judge:`
  line and fails no build by the count. Tadas's managers hold nineteen
  at most, so it names none, and Tadas recorded no exception for the
  count. (#196)
- **The guideline pin moves to v0.46.0.** `main` merges the `scaffold`
  branch at v0.46.0. (#196)

Every release's notes stay on the repository host: <https://github.com/baristaze/tadas/releases>.
